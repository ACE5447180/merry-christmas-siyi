# 小冯 × 小怡 · Christmas 2026

电影感雪夜主题的移动端圣诞网页，为小怡定制。

## 在线访问

- 微信 / 浏览器：<https://ace5447180.github.io/merry-christmas-siyi/>
- GitHub 仓库：<https://github.com/ACE5447180/merry-christmas-siyi>

页面已经部署为可分享的 HTTPS 站点，并设置为不主动让搜索引擎收录。照片和页面仍属于公开链接，请只发送给需要查看的人。

## 页面内容

- 以 `2026-12-25T00:00:00+08:00` 为目标的实时倒计时，每秒更新。
- 小怡的真实照片画廊，保留原本质感，只做构图裁切。
- 由 Canvas 绘制的动态粒子圣诞树，可旋转、闪烁，并支持轻触点亮。
- 可轻触查看大图的电影画幅浏览体验。
- 可点选的圣诞夜愿望清单。
- 可拆开的圣诞信和最终告白。

## 本地打开

直接双击 `index.html`。

手机端预览位于 `preview/mobile-full.png`，其余逐屏截图也保存在 `preview/`。

## 已验证

- 实时倒计时每秒更新，目标时间为香港时间 `2026-12-25 00:00:00`。
- 390 × 844 和 320 × 640 两种手机视口均无横向溢出。
- 照片大图、愿望清单、拆信弹层和页面滚动锁定均已实际测试。
- 粒子树已验证会持续动画，点亮按钮会改变愿望文案并触发粒子扩散。
- 粒子树只在进入可视区域时运行，离开可视区域或切到后台后会暂停。
- 所有图片均可在离线状态下从本地 `assets/` 加载。

## 照片说明

照片位于 `assets/`，仅用于这个圣诞页面。GitHub Pages 需要公开仓库，页面链接本身也会被拿到链接的人访问。
